# 알림 메시지 관리 설계

- 날짜: 2026-07-30
- 상태: 승인됨
- 관련 설계: `2026-07-29-smile-frequency-window-reminders-design.md`

## 배경

반복 알림의 제목과 본문이 하나로 고정되어 있어 여러 번 받으면 단조롭게 느껴진다. 사용자가 미소 알림 문구를 직접 추가·수정·삭제하고, 사용할 순서를 정할 수 있게 한다.

## 목표

- 첫 실행부터 사용할 수 있는 비평가적 기본 메시지를 8개 제공한다.
- 설정의 “메시지 관리”에서 추가, 수정, 삭제, 드래그 순서 변경을 지원한다.
- 목록은 기기의 `UserDefaults`에만 저장한다.
- 알림 시간 목록에 메시지를 위에서부터 순서대로 배정하고, 메시지 수를 넘으면 처음부터 반복한다.
- 메시지 변경 후 “알림 설정 저장”을 누르면 새 알림 그룹을 먼저 등록하고 기존 그룹을 교체한다.

## 모델과 저장

`ReminderMessage`는 안정적인 `id`와 사용자가 보는 `text`를 가진 `Codable` 값 타입이다. `UserDefaultsReminderMessageStore`는 배열 전체를 JSON으로 저장한다. 저장값이 없거나 손상되었거나 비어 있으면 기본 목록을 반환한다.

메시지는 공백을 제거한 뒤 저장하며 빈 값, 100자 초과, 완전히 같은 중복 문구는 거부한다. 알림 동작을 유지하기 위해 마지막 한 개는 삭제할 수 없다.

## 알림 표시

- 제목: `스마일데이`
- 본문: 사용자가 정렬한 메시지
- 각 반복 시각의 인덱스에 `messages[index % messages.count]`를 배정한다.
- payload와 알림 식별자 규칙은 바꾸지 않는다.

## 카피 원칙

기본 문구는 짧고 즉시 행동할 수 있으며 무표정을 결함으로 표현하지 않는다. “리프팅”, “젊어진다”, “교정”, “치료”, 외모·감정 평가 표현은 사용하지 않는다.

## 완료 기준

- 기본 메시지가 6개 이상이고 모두 고유하다.
- 추가·수정·삭제·순서 변경이 즉시 로컬 저장소에 반영된다.
- 빈 값, 중복, 100자 초과, 마지막 메시지 삭제가 방지된다.
- 저장된 메시지 순서가 스케줄러에 전달된다.
- CoachingKit 전체 테스트와 iOS 앱 빌드가 통과한다.
