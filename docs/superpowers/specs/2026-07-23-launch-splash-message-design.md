# 런치 스플래시 메시지 - 설계안

## 배경
앱을 열 때마다 사용자에게 위로가 되는 고정 문구를 보여주고 싶다. OS가 자동 생성하는 런치 스크린(`INFOPLIST_KEY_UILaunchScreen_Generation = YES`)은 완전히 정적이라 문구를 넣을 수 없으므로, `RootView`의 데이터 로딩 구간에 커스텀 스플래시 화면을 넣는다.

## 요구사항
- 문구: "웃다보면 다 좋아질거야" (고정, 랜덤 아님)
- 노출 시점: 앱을 실행할 때마다 매번 (최초 1회 한정 아님)
- 스타일: 텍스트만 추가하는 게 아니라, 앱 아이콘/로고와 문구가 함께 있는 전용 스플래시 화면
- 최소 노출 시간: 1.2~1.5초 고정. 실제 데이터 로딩이 이보다 빨리 끝나도 최소 시간은 채운 뒤 넘어간다. 로딩이 더 오래 걸리면 로딩 완료 시점까지 보여준다.
- 스킵(탭하여 건너뛰기) 기능 없음.

## 설계

### 1. 구성 요소
- `SmileDay/Views/Splash/SplashView.swift` 신규 파일.
- 배경: `SDColor.primaryGradient` (코랄 계열 그라디언트, Morning Glow 톤과 통일).
- 시각 요소: `SmileArc` 곡선 + 앱 이름("스마일데이") + 고정 문구 "웃다보면 다 좋아질거야".
- 기존 `Views/Onboarding` 옆에 `Views/Splash` 폴더를 신설해 역할을 분리한다.

### 2. RootView 동작 변경
- `isLoading` 분기에서 보여주던 `ProgressView()`를 `SplashView()`로 교체한다.
- `.task` 내부에서 실제 데이터 로딩과 "최소 1.3초 대기"를 `async let`으로 동시에 실행하고, 둘 다 끝난 뒤 `withAnimation`으로 다음 화면(메인 탭 / 온보딩 / 기준선 촬영)으로 페이드 전환한다.

### 3. 에러 처리
- 기준선 조회 실패는 기존과 동일하게 무시(`try?`)한다. 새로운 실패 케이스는 없다.

### 4. 테스트
- 뷰 자체는 로직이 거의 없으므로 별도 유닛 테스트 대신 시뮬레이터 실행으로 육안 확인한다.

## 범위 밖

- 탭 스킵
- 최초 1회만 노출하는 옵션
