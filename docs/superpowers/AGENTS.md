# superpowers

## Purpose
Feature documents from the superpowers workflow. Specs and plans pair 1:1 via filename — `YYYY-MM-DD-<feature>-design.md` (spec) ↔ `YYYY-MM-DD-<feature>.md` (plan).

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `specs/` | Design specs — the "what/why": header (날짜/상태/배경), goals, Swift type sketches |
| `plans/` | Implementation plans — the "how": Task/Step checkboxes, named files, verification commands |

## For AI Agents

### Working In This Directory
- Not every plan has a companion spec. The older English UI plans (care-icon timer hero, launch splash message) predate the pairing convention.
- A plan's checked boxes are a record of what was executed, not a description of current code. When a feature is later removed or reworked, add a dated note at the top rather than unchecking boxes — `2026-07-30-live-smile-session-graph.md` is the worked example.
